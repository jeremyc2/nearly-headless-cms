# Context Map

## Contexts

- [CMS Construction](./docs/contexts/cms-construction/CONTEXT.md): the language CMS Builders use to define and operate headless CMSs with the reusable library
- [Example Blog](./docs/contexts/example-blog/CONTEXT.md): the content language exercised by the full blog reference implementation

## Relationships

- **CMS Construction → Example Blog**: the Example CMS applies the library's definitions and operations to author and serve Example Blog content.
- **Example CMS → Public Blog**: the public blog consumes content from the headless Example CMS and owns its presentation.
